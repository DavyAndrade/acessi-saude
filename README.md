# AcessiSaúde-Audit

Ferramenta Computacional de Auditoria Contínua de Acessibilidade Web (WCAG/LBI) para Plataformas Públicas de Saúde

## Artigo Científico Associado

**Auditoria Algorítmica de Acessibilidade em Plataformas Digitais de Saúde no Rio de Janeiro: Uma Análise Interdisciplinar sob a Ótica da LBI e do Direito à Saúde**

## Sobre o Projeto

MVP de aplicação/dashboard que realiza varreduras automáticas (web scraping + análise DOM) em portais e aplicativos de saúde pública:

- **e-SUS**
- **Conecte SUS**
- **Agendamentos municipais**

## Funcionalidades

- Auditoria contínua de conformidade com **WCAG 2.1** (níveis A e AA)
- Verificação de conformidade com a **Lei Brasileira de Inclusão (Lei nº 13.146/2015)**
- Geração de relatórios de atrito de navegação:
  - Falhas de contraste
  - Falta de suporte a leitores de tela
  - Consumo excessivo de dados móveis
- Identificação de pontos jurídicos e técnicos de violação de direitos do usuário periférico

## Stack Tecnológica

- Web scraping / automação de navegador
- Análise de DOM e acessibilidade
- Geração de relatórios técnicos e jurídicos
